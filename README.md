# MyGithub

The official Github web app has been a massive source of frustration for me, especially for the past few years after Microsoft acquired Github.

MyGithub is my own custom Github client that should theoretically provide a better user experience than the official Github web app.

This is merely an ambitious personal project of mine, and I do not expect it to be perfect or even usable in the near future. However, I will try my best to make it as good as possible.

I'll be focusing for the moment on the frustrations I have with the official Github web app.

### Adding a dependency

When introducing a new third-party dependency:

Add the dependency using the project's normal dependency management process.
Check the dependency's license and confirm that it permits use and distribution with this project.
Add an entry for the dependency to THIRD-PARTY-NOTICES.
Include, at minimum:
The dependency name.
The version used.
The copyright holder(s), where applicable.
The license name.
A link to the dependency's upstream repository or project page.
The applicable license text or required attribution notices.
If the dependency is updated to a new version, review its license and update the corresponding notice if necessary.

Example:

```md
## Example Library

Version: 1.2.3
License: MIT
Copyright: Copyright (c) 2026 Example Author
Source: https://github.com/example/example-library

[MIT License text]
```

Do not remove or replace existing third-party notices when adding a dependency. Each dependency remains subject to the terms of its own license.
